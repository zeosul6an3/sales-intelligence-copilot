# Data source and licence

The built-in example dataset is **Online Retail II**, from the UCI Machine Learning Repository.

- **Creator:** Daqing Chen
- **Citation:** Chen, D. (2012). *Online Retail II* [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5CG6D
- **Source page:** https://archive.ics.uci.edu/dataset/502/online+retail+ii
- **Licence:** Creative Commons Attribution 4.0 International (CC BY 4.0), https://creativecommons.org/licenses/by/4.0/

## Description
Historical transactions of a UK-based, non-store online retailer of all-occasion gift-ware, many of whose customers are wholesalers. The data covers 1 December 2009 to 9 December 2011. Prices are in **pounds sterling (GBP, £)**, and this project keeps that original currency.

## How this project uses it
- The raw file is downloaded from the official source by a script. It is **not** stored in this repository.
- Cleaning rules are documented, and every affected row is counted. No records are dropped silently.
- The dataset has no cost or inventory data, so this project makes **no profit, margin or stock-availability claims** from it.

This file covers the dataset only. The project's own source code has no licence yet.
